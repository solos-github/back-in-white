# Back in White

Browserbasiertes Götterspiel (Fanprojekt nach Vorbild von Black & White) mit einem Babygorilla als Kreatur.

## Spielen

`index.html` im Browser öffnen (Chrome oder Edge empfohlen). Die Ordner `models/`, `voice/`, `music/` und `sounds/` müssen daneben liegen. Three.js wird beim Start von einem CDN geladen, es braucht also Internet.

Der Spielstand wird automatisch gespeichert (Browser und, wenn erlaubt, als `kleiner-gott-spielstand.json` im Spielordner).

## Inhalt

- `index.html`: das komplette Spiel
- `models/`: 3D-Modelle als eingebettete JS-Dateien
- `voice/`: Sprachausgabe der Figuren (mp3)
- `music/`, `sounds/`: Musik und Kreaturenlaute

Werkzeuge zum Erzeugen der Sprachdateien, Rohmodelle und Sicherungskopien liegen bewusst nicht in diesem Repository.
